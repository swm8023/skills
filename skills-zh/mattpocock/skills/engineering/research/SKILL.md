---
name: research
description: 对照高可信的一手来源调查问题，并将发现保存为仓库中的 Markdown 文件。当用户要求研究主题、收集文档或 API 事实，或将阅读调查交给 background agent 时使用。
---

启动 **background agent** 完成研究，让你在它阅读时继续工作。

它的任务：

1. 对照 **primary source**（官方文档、源代码、spec、第一方 API）调查问题，而不是阅读这些来源的二手总结。把每个说法追溯到拥有该事实的来源。
2. 将发现写入一份 Markdown 文件，为每个说法引用来源。
3. 保存到仓库已有的此类笔记位置，遵循现有约定；若没有约定，放到合理位置并说明路径。
