# Triage Labels

skill 使用五个规范 triage 角色。本文件将角色映射到仓库 issue tracker 的实际标签字符串。

| mattpocock/skills 中的标签 | 我们 tracker 的标签 | 含义 |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage` | `needs-triage` | 需要维护者评估 issue |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可交给 AFK agent |
| `ready-for-human` | `ready-for-human` | 需要人工实施 |
| `wontfix` | `wontfix` | 不会采取行动 |

skill 提及角色（例如“添加 AFK-ready triage 标签”）时，使用本表对应的标签字符串。

修改“我们 tracker 的标签”列，匹配实际使用的词汇。
