# Misc

保留但很少使用的工具，不进入正式 plugin。

- **[git-guardrails-claude-code](./git-guardrails-claude-code/SKILL.md)**：设置 Claude Code hook，在执行前阻止危险 Git 命令（push、reset --hard、clean 等）。
- **[migrate-to-shoehorn](./migrate-to-shoehorn/SKILL.md)**：将测试的 `as` 断言迁移到 @total-typescript/shoehorn。
- **[scaffold-exercises](./scaffold-exercises/SKILL.md)**：创建 section、problem、solution 和 explainer 练习目录。
- **[setup-pre-commit](./setup-pre-commit/SKILL.md)**：设置 Husky pre-commit，运行 lint-staged、Prettier、类型检查和测试。
