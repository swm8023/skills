# RESOURCES.md Format

`RESOURCES.md` 是本主题精选的可信来源集合。解释所需知识从这里获取，而不是靠参数化猜测。Wisdom 来自这里列出的 community。

## Structure

```md
# {Topic} Resources

## Knowledge

- [Book: _The Science and Practice of Strength Training_ by Zatsiorsky & Kraemer](https://example.com)
  Foundational text on programming and adaptation. Use for: anything to do with periodisation, recovery, intensity zones.
- [Article: "How Much Should I Train?" by Greg Nuckols (Stronger By Science)](https://example.com)
  Evidence-based review of volume landmarks. Use for: weekly set targets per muscle group.

## Wisdom (Communities)

- [r/weightroom](https://reddit.com/r/weightroom)
  High-signal subreddit, moderated against bro-science. Use for: programme critique, plateau troubleshooting.
- Local: Tuesday strength class at {gym name}
  Use for: real-time coaching feedback on lifts.
```

## Rules

- **仅高可信来源。** 优先一手来源、公认专家、同行评审研究、管理良好的 community。伪装成教育的营销资料排除。
- **每项加说明。** 三个月后裸链接没有用。加一句：覆盖什么、何时查阅。
- **按 Knowledge / Wisdom 分组。** 对应 [SKILL.md](./SKILL.md) 的理念。资源只属于一组也可以。
- **明确列出缺口。** mission 需要的区域没有好资源时，用 `## Gaps` 列出缺失内容，指导后续搜索。
- **严格删减。** 发现资源错误、浅薄或偏离 mission 时删除，而非埋着。五个精准来源好过三十个平庸来源。
- **记录 community 偏好。** 用户不愿加入 community 时在这里注明，避免以后重复建议。
