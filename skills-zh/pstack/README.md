## 翻译与润色

先逐句翻译，再按 [humanizer-zh](https://github.com/op7418/Humanizer-zh/blob/f4518a8eab97b8bfebc66a89d34320a89bef6930/SKILL.md) 的规则检查中文语序、冗余表达和术语搭配。润色以原文为依据，保留每条规则的含义、条件、数量、例外和语气强度。

原文和译文均为 106 行。保持原行、空行、英文标题与 anchor、段落顺序、列表结构和引用位置。用于英语语法与文体辨析的英文原句保留，并在同一行提供中文；代码、行内代码、路径、命令、名称、YAML key 和调用策略保持原样。自然语言 description 译为中文，LICENSE 原样保留。

译文保留英语规则的原始适用范围，以及上游的显式调用策略和 `unslop` 引用。`unslop` 属于本次选取范围之外的配套 skill。这里仅保存参考资料，与项目运行时的 `../../skills/` 分开。
