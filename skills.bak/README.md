# Original skill archives

This directory stores upstream material for reference. Active project skills
live in `../skills/`.

- [Matt Pocock complete snapshot](mattpocock/README.md): all 190 tracked upstream
  files at `49dd158d1076134a641b33efb035946536778336`, verified on 2026-10-14.
  The skill library contains 38 skills: 27 stable, 7 experimental, and 4 frozen.
- [Source manifest](mattpocock.UPSTREAM.json): repository, commit, file modes,
  and SHA-256 hashes for checking the snapshot.
- [Chinese skill library](../skills-zh/mattpocock/README.md): corresponding
  translation of every skill and its Markdown references.
- `legacy-mattpocock-2026-06/`: the 13 old Matt Pocock skill folders previously
  stored flat in this directory. Preserved as historical material, not current
  upstream instructions.

Other existing skill folders are from other sources and remain unchanged.
The Matt Pocock snapshot preserves the upstream symlink blob `AGENTS.md` as
a plain file containing `CLAUDE.md` on Windows; its original mode is recorded
in the source manifest. Executable script modes are preserved in Git.
